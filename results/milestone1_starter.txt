  python app.py ask 'silk slip dress in midi length under $40'
  python app.py ask 'platform sneakers size 8'

And one the data cannot match — this is the empty-search branch:

  python app.py ask 'designer ballgown size XXS under $5'

Single quotes on purpose. In PowerShell a query in "double quotes"
loses the $30 — it gets read as a variable — and you search with no
price ceiling, with nothing to tell you it happened.
